# Stage 6: Differentiate

Propose **three** ideas (start from the hypotheses in `.agents/context/hackathon.md`, keeping only
those the data supports). Score each 1-5 in a table: business value, technical novelty,
feasibility in the remaining time, evidence from the dataset, demo impact, implementation risk
(lower is better). Give a one-line rationale per score and a recommendation.

The chosen idea is a WOW layer on a working core, never a replacement for it. Get the user's
choice before building.
