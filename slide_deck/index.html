03 // History detectorEach point keeps its own history

Learn what is usual here.

01 // BASELINE

Look back

Use the previous 28 calendar days, with at least 14 valid days. Find the median and robust spread.

02 // EVIDENCE

Check today

Measure deviation from the baseline. Also flag stuck values, unexpected zeros and negative values.

03 // OUTPUT

Form cases

Group nearby flagged days. Rank by rule hits, duration and peak score; preserve reasons and source references.

SafeguardMissing, duplicate or insufficient history can leave a reading unscored; unscored is not normal.
